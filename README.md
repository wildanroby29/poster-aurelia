# MIRRORWELL OASIS — The Poster for a Place That Isn't There

A painterly gouache travel poster for Mirrorwell Oasis, a place that isn't there — a tranquil circular reflecting pool and an arched adobe resort pavilion nestled among warm dunes and palm silhouettes at sunset, with visitors resting along a tiled courtyard path. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty.

Run: `python3 main.py` (writes the poster to `MAKEFUN_OUTPUT_DIR/entry.png`, or `/output/entry.png`).
