# CORALIS — The Poster for a Place That Isn't There

A flat vector travel poster for Coralis, a lagoon city beneath a coral arch — a stone-and-coral archway, a terraced pagoda and a fan coral tree, drawn deterministically in Python. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty.

Run: `python3 main.py` (writes the poster to `MAKEFUN_OUTPUT_DIR/entry.png`, or `/output/entry.png`).
