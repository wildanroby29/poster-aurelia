# CORALIS — The Poster for a Place That Isn't There

A flat layered gouache and screenprint travel poster for Coralis, a place that isn't there — a stone-and-coral archway with CORALIS curved along it, a rocky island sanctuary with a tall fluted spire and coral shelf ledges, a rowboat with one rower and three visitors on the promenade. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty.

Run: `python3 main.py` (writes the poster to `MAKEFUN_OUTPUT_DIR/entry.png`, or `/output/entry.png`).
