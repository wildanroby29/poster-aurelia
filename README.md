# CASSIAN — The Poster for a Place That Isn't There

A flat vector travel poster for Cassian, a place that isn't there — a giant open seashell on a calm beach at dusk, warm lit rooms glowing inside the shell, a couple walking on the sand. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty.

Run: `python3 main.py` (writes the poster to `MAKEFUN_OUTPUT_DIR/entry.png`, or `/output/entry.png`).
